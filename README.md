# Hue — Random Color Palette Generator

A responsive palette studio with fresh color generation, mood presets, locked swatches, clipboard copy, and CSS export. Built with vanilla JavaScript, Vite, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The GitHub Actions workflow in `.github/workflows/deploy.yml` builds and deploys the app to GitHub Pages when pushed to `main`.
